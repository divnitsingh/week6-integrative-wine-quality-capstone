# Dataset Attribution

**Dataset:** Wine Quality — Red Wine  
**Provider:** UCI Machine Learning Repository  
**Official dataset page:** https://archive.ics.uci.edu/dataset/186/wine+quality  
**Official red-wine CSV:** https://archive.ics.uci.edu/ml/machine-learning-databases/wine-quality/winequality-red.csv  
**Dataset DOI:** https://doi.org/10.24432/C56S3T

UCI describes the Wine Quality dataset as supporting both classification and regression tasks and states that the dataset contains physicochemical input variables and a wine-quality output variable. The UCI page lists the dataset under a **Creative Commons Attribution 4.0 International (CC BY 4.0)** license.

Please retain this attribution when publishing or sharing the project.
